Cara menghubungkan akun MT5 ke halaman ini

Halaman ini membaca data/account.json (diperbarui otomatis tiap 60 detik). Format yang dibaca:

{
  "account": { "login": "****1234", "server": "Broker-Live", "currency": "USD",
               "balance": 1250.40, "equity": 1262.10, "leverage": 500,
               "updated": "2026-10-16T08:30:00" },
  "initial_deposit": 1000,
  "deals": [
    { "ticket": 1, "time": "2026-10-15T14:20:00", "open_time": "2026-10-15T13:05:00",
      "symbol": "XAUUSD", "type": "buy", "volume": 0.10, "magic": 20250,
      "profit": 12.5, "commission": -0.7, "swap": 0 }
  ],
  "open_positions": [
    { "ticket": 9, "symbol": "EURUSD", "type": "sell", "volume": 0.1,
      "open_time": "2026-10-16T07:10:00", "open_price": 1.0842, "profit": 3.2 }
  ]
}

File itu bisa dibuat otomatis oleh export_mt5_stats.py (di folder yang sama), yang membaca riwayat langsung dari terminal MT5 Anda.

Trading memiliki risiko kerugian. Hasil masa lalu tidak menjamin hasil mendatang. Statistik dihitung dari transaksi yang sudah ditutup, setelah komisi dan swap.
