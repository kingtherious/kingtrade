API Key & Keamanan

Kelola rotasi secret melalui backend/secret manager. Jangan menyimpan API secret di JavaScript publik, GitHub Pages, atau repository.

Rekomendasi: HTTPS, rate limiting, validasi payload, token bertanda tangan atau kredensial per lisensi, expiry/nonce untuk mencegah replay, dan audit log.

Manajemen Admin User

Pembuatan admin harus dilakukan oleh admin yang sudah terautentikasi. Simpan password menggunakan Argon2id atau bcrypt di backend, bukan plaintext di file HTML.
